# Hawk Trade — الموقع

موقع ثابت (HTML/CSS/JS) يُنشر عبر GitHub Pages.

## الصفحات
| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `products.html` | المنتجات |
| `group.html` | المجموعة |
| `contact.html` | تواصل |

الملفات المشتركة: `assets/site.css` (التصميم) و `assets/site.js` (اللغة + القائمة + نموذج "اترك بياناتك").
الصور في مجلد `img/`، وصورة معاينة الروابط (واتساب/فيسبوك) هي `og.jpg`.

## تعديل النصوص
كل نص له مفتاح `data-t="..."`. النص العربي مكتوب داخل الصفحة،
والترجمة الإنجليزية في جدول `T` أعلى `assets/site.js`.
لتغيير نص: عدّله في الصفحة **و** في الجدول (العنصر الأول = عربي، الثاني = إنجليزي).

## رقم الواتساب والهاتف
في أول `assets/site.js`:

```js
var WA  = "201551876540";   // رقم الواتساب بدون +
var TEL = "+201551876540";
```

الروابط المكتوبة داخل صفحات HTML (`wa.me/...`) تُحدَّث تلقائيًا من هذا الرقم عند فتح الصفحة.

## استقبال بيانات العملاء
زر **"اترك بياناتك"** يفتح نموذجًا صغيرًا (اسم + رقم + ملاحظة).

- **الوضع الحالي:** يفتح رسالة واتساب جاهزة بالبيانات.
- **لاستقبالها على الإيميل/شيت بدل واتساب:** أنشئ نموذجًا على
  [Formspree](https://formspree.io) أو [FormSubmit](https://formsubmit.co) وضع الرابط في أول `assets/site.js`:

```js
var LEAD_ENDPOINT = "https://formspree.io/f/XXXXXXX";
```

عندها تُرسل البيانات مباشرة ويظهر للعميل "وصلنا طلبك" بدون فتح واتساب.
