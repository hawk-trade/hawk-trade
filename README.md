# Hawk Trade — الموقع

موقع ثابت (HTML/CSS/JS) يُنشر عبر GitHub Pages.

## الصفحات
| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `products.html` | المنتجات |
| `group.html` | المجموعة |
| `contact.html` | تواصل |

الملفات المشتركة: `assets/site.css` (التصميم) و `assets/site.js` (اللغة + القائمة + نموذج "اترك بياناتك").
الصور في مجلد `img/`، وصورة معاينة الروابط (واتساب/فيسبوك) هي `og.jpg`.

## تعديل النصوص
كل نص له مفتاح `data-t="..."`. النص العربي مكتوب داخل الصفحة،
والترجمة الإنجليزية في جدول `T` أعلى `assets/site.js`.
لتغيير نص: عدّله في الصفحة **و** في الجدول (العنصر الأول = عربي، الثاني = إنجليزي).

## رقم الواتساب والهاتف
في أول `assets/site.js`:

```js
var WA  = "201551876540";   // رقم الواتساب بدون +
var TEL = "+201551876540";
```

الروابط المكتوبة داخل صفحات HTML (`wa.me/...`) تُحدَّث تلقائيًا من هذا الرقم عند فتح الصفحة.

## استقبال بيانات العملاء على الإيميل

زر **"اترك بياناتك"** يفتح نموذجًا صغيرًا (اسم + رقم + إيميل + ملاحظة)،
وصفحة `contact.html` فيها النموذج الكامل.

### التفعيل (خطوة واحدة)
افتح `assets/site.js` وضع إيميلك في أول سطر:

```js
var LEAD_EMAIL = "sales@example.com";
```

أول رسالة تُرسَل من الموقع يوصلك عليها إيميل تفعيل من **FormSubmit** —
اضغط رابط التفعيل مرة واحدة فقط، وبعدها كل الطلبات توصلك على الإيميل تلقائيًا
بجدول منسّق (الاسم، الهاتف، الإيميل، الشركة، المدينة، النشاط، الأصناف، الكمية).

تفعيل `LEAD_EMAIL` كمان بيظهر إيميلك في صفحة "تواصل" وفي الفوتر تلقائيًا.
لو تُرك فارغًا: الإيميل يختفي من الموقع والزر يفتح رسالة واتساب جاهزة بدلًا منه.

### بديل (اختياري)
لو تفضّل Formspree أو أي خدمة أخرى، ضع رابطها في `LEAD_ENDPOINT` وهو
يتقدّم على `LEAD_EMAIL`:

```js
var LEAD_ENDPOINT = "https://formspree.io/f/XXXXXXX";
```
