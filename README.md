# Hawk Trade — الموقع

موقع ثابت (HTML/CSS/JS) يُنشر عبر GitHub Pages — بدون أي إطار عمل أو خطوة بناء.
**الرابط:** https://hawk-trade.github.io/hawk-trade/

## الصفحات
| الملف | الصفحة |
|---|---|
| `index.html` | الرئيسية |
| `products.html` | المنتجات والقطاعات |
| `group.html` | مجموعة HTS وشركاتها |
| `contact.html` | تواصل + الأسئلة المتكررة |

الملفات المشتركة: `assets/site.css` (التصميم) و `assets/site.js` (اللغة + القائمة + النموذج + اللودر).
الصور في `img/`، وصورة معاينة الروابط `og.jpg`.

## تعديل النصوص
كل نص له مفتاح `data-t="..."`. النص **العربي** مكتوب داخل صفحة HTML،
والترجمة **الإنجليزية** في جدول `T` أعلى `assets/site.js`.
لتغيير نص: عدّله في الصفحة **وفي** الجدول (الأول عربي، الثاني إنجليزي).

## الإعدادات — أول `assets/site.js`
```js
var LEAD_EMAIL    = "info@htstradegroup.com"; // الإيميل اللي توصل عليه الطلبات
var LEAD_ENDPOINT = "";                        // بديل اختياري (Formspree …) ويتقدّم على الإيميل
var WA  = "201215557314";                      // واتساب بدون +
var TEL = "+201215557314";
```

### استقبال الطلبات على الإيميل
زر **"اترك بياناتك"** يفتح نموذجًا سريعًا (اسم + رقم + إيميل + ملاحظة).
أول رسالة تُرسَل يصل إيميل تفعيل من **FormSubmit** — اضغط رابط التفعيل مرة واحدة،
وبعدها كل الطلبات توصل بجدول منسّق. لو `LEAD_EMAIL` فاضي، الزر يفتح واتساب بدلًا منه.

## الصور
- `hero-wide / hero-tall` — خلفية الصفحة الرئيسية
- `sec-*` — خلفيات كروت القطاعات
- `st-*` — عناصر مقصوصة بخلفية شفافة (تُستخدم في الأنيميشن وكعناصر زخرفية)
- `step-1…4` — مراحل العمل · `bg-*` — خلفيات الأقسام · `co-*` — لوجوهات شركات المجموعة
- `BRIEF-IMAGES.md` — بريف توليد صور جديدة بنفس الهوية

## الأنيميشن
- **اللودر:** عربية نقل بعجل دوّار تظهر عند فتح أي صفحة والانتقال بينها (`.loader` في كل صفحة).
- **مشهد الرحلة:** SVG في قسم "رحلة شحنتك ويانا" — طيارة وباخرة وعربية تتحرك على مسارات `animateMotion`.
- كل الأنيميشن يتوقف تلقائيًا لمن يفعّل `prefers-reduced-motion`.

Settings → Pages → Branch: `main` / root. التحديث يظهر خلال دقيقة من كل دفعة.
